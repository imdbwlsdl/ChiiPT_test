# 힐링 동작 (쓰다듬기 반응 연출)

팀 프로젝트 [ChiiPT](https://github.com/HongJC-PortFolio/ChiiPT)에서 내가 맡은 **힐링 파트 중 "캐릭터가 쓰다듬기에 반응하는 연출"** 부분만 모아 둔 폴더입니다.

> 쓰다듬기를 **인식**하는 코드(손 랜드마크 → petting 판정)는 팀원(yugi-62)이 작성했고, 이 저장소에는 포함하지 않았습니다.
> 이 폴더의 코드는 "petting 인가?"라는 결과만 받아서 **캐릭터가 어떻게 반응할지**를 맡습니다.
> (AI 코딩 도구 Claude Code와 단계별로 설명을 들으며 함께 작성했습니다.)

## 동작

쓰다듬는 동안 세 동작을 차례로 반복하고, 손을 멈추면 원래 모습으로 돌아옵니다.

| 순서 | 동작 | 모습 | 효과 |
|---|---|---|---|
| 1 | 부비부비 (1.7초) | 손에 몸을 비비듯 좌우로 천천히 흔들림 | 💗 가끔 |
| 2 | 웃음 (1.1초) | 작게 파르르 떨림 | `ㅎㅎ` `✨` |
| 3 | 총총 (1.35초) | 3번 뛰어오름 | ❤️ 많이 |

인식이 잠깐 끊겨도 어색하지 않도록 세 가지를 넣었습니다.
- **유예(0.8초)**: 멈춤 신호가 와도 잠깐은 계속 반응 (잠깐 가려지는 것은 무시)
- **이어하기(4초)**: 멈춘 직후 다시 쓰다듬으면 처음이 아니라 하던 동작부터
- **출렁 복귀**: 정말 멈추면 뚝 끊기지 않고 살짝 출렁이며 원래대로

## 폴더 구성

```
healing-motions/
├── team-structure/        # 팀 저장소 구조(features/healing/)에 맞춘 버전
│   ├── PetReactions.ts    #   Web Animations API 사용, 다른 파트 파일은 수정하지 않음
│   └── healing-index.patch#   features/healing/index.ts에 연결하는 변경(약 10줄)
└── standalone-demo/       # 팀 코드 없이 단독 테스트하던 버전 (CSS 애니메이션)
    ├── PetReactions.ts
    └── reactions.css
```

### team-structure
- `#character` 요소를 읽기 전용으로 찾아 `element.animate()`로 움직입니다. (앱의 CSP가 인라인 `<style>`을 막아서 CSS 파일 대신 JS 애니메이션을 사용)
- 캐릭터가 잠든 상태이거나 달리는 중(자세 반응)이면 연출하지 않습니다. 자세 반응이 우선이라는 가정이며, 팀과 합의가 필요한 부분입니다.
- 연결 방법은 `healing-index.patch` 참고: 인식 결과가 나갈 때 `reactions.setPetting(result.state === 'petting')`을 함께 호출하고, 카메라 시작/중지에서 `attach()` / `detach()`를 호출합니다.

### standalone-demo
- CSS 클래스(`rub` / `laugh` / `hop` / `settle`)를 붙였다 떼는 방식이라 구조가 단순해서 원리를 이해하기 좋습니다.
- `reactions.css`는 해당 클래스의 애니메이션과 하트 스타일입니다.

## 조절하는 값 (`PetReactions.ts` 맨 위)

| 값 | 의미 |
|---|---|
| `SEQUENCE` | 동작 순서, 길이(ms), 효과가 나오는 간격(ms) |
| `GRACE_MS` | 인식이 꺼져도 기다려 주는 시간 |
| `RESUME_WITHIN_MS` | 이 시간 안에 다시 쓰다듬으면 이어서 진행 |

## 알려진 한계
- 지금은 한 컷 이미지를 움직이는 방식이라 표정 변화는 없습니다. (표정 그림이 생기면 교체하기 쉽게 연출 코드를 분리해 둠)
- 캐릭터가 달리는 중인지는 팀장님 렌더러가 화면에 남기는 표시(`data-at-home`)를 읽어서 판단합니다. 정식 API로 바꾸는 것이 좋습니다.
- 이 폴더는 단독으로 실행되지 않습니다. 팀 저장소의 힐링 인식 코드와 함께 사용합니다.
