# 캐릭터 프레임 (새 캐릭터)

영상/GIF에서 추출한 투명 PNG 프레임. 파일명: `동작/동작-frame-NN.png`

| 동작 | 프레임 | 캔버스 | 설명 |
|---|---|---|---|
| idle | 6 | 256x240 | 눈 뜬 대기 |
| idle-closed | 10 | 256x240 | 눈 감은 대기 |
| walk | 14 | 256x240 | 제자리 걷기 (원본 방향) |
| walk-mirrored | 14 | 256x240 | 제자리 걷기 (좌우 반전) |
| stretch | 28 | 256x240 | 기지개 |
| cheek-pull | 29 | 256x240 | 볼 꼬집어 늘어남 |
| cheek-release | 17 | 256x240 | 늘어난 볼이 풀림 |
| sleep | 57 | 320x300 | 침대에서 자는 모습 (6fps 추출) |

- 서 있는 캐릭터의 몸 높이는 모든 동작에서 약 150px, 발바닥 기준선은 캔버스 아래에서 12px 위로 통일.
- 배경과 그림자는 제거함 (그림자는 렌더러가 직접 그림). 가장자리의 하얀 테두리 번짐은 두 번 정리함(밝은 가장자리 제거 + 마지막 1픽셀을 외곽선 색으로 칠함 + 떨어진 점 제거).
- 원본 GIF 프레임 간격: idle 120ms, idle-closed 120ms, walk 60ms. 영상은 15fps(sleep은 6fps)로 추출, 멈춘 구간의 중복 프레임은 합침.
