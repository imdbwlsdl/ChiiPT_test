# 힐링 데모: 새 캐릭터 + 쓰다듬기 + 산책

팀 프로젝트 [ChiiPT](https://github.com/HongJC-PortFolio/ChiiPT)의 힐링 파트를 **팀 코드와 분리해서 테스트**하던 데모(`ChiiPT-demo`)의 기록입니다. 이 폴더에는 **내가 작성한 파일만** 담았고, 다른 팀원의 코드와 캐릭터 이미지는 포함하지 않았습니다.
(AI 코딩 도구 Claude Code와 단계별로 설명을 들으며 함께 작성했습니다.)

## 데모에서 되는 것
| 기능 | 설명 |
|---|---|
| 새 캐릭터 프레임 재생 | 대기(`idle-open`) / 눈 감은 대기(`idle-closed`) / 걷기(좌우)를 프레임 PNG로 재생 |
| 쓰다듬기 반응 | 힐링 모드에서 쓰다듬으면 눈 감은 얼굴 + 부비부비 → 웃음 → 총총, 하트 |
| 산책 | 마우스를 따라 화면 어디든(좌우·상하·대각선) 걷고, 끄면 **화면 아래 가운데**로 걸어서 돌아옴 |

- 우클릭 메뉴(캐릭터 몸 위에서)에서 `힐링 모드`(카메라 + 쓰다듬기)와 `산책`을 켜고 끕니다.
- **걷는 동안에는 쓰다듬기 반응을 쉬고**, 멈춰 있을 때만 반응합니다.
- 걷는 방향에 따라 좌우 프레임(`walk` / `walk-mirrored`)을 번갈아 씁니다.
- 쓰다듬기 인식(손 랜드마크 → petting 판정)은 팀원(yugi-62)의 코드를 그대로 사용했습니다.
- 수면·기상은 내 파트가 아니라서 데모에서 뺐습니다. 볼 꼬집기·놓기, 기지개 프레임은 이미지만 보관합니다.

## 파일 (`src/`)
| 파일 | 역할 |
|---|---|
| `motions.ts` | 동작 목록. 프레임 수, 재생 속도(fps), 캔버스 크기, 발바닥 기준선 |
| `CharacterView.ts` | 프레임 재생, 위치(발바닥 중앙 좌표), 클릭 영역(몸 위 타원) |
| `WalkController.ts` | 산책 이동 계산. 커서를 따라가고, 멈추는 거리/속도 등 숫자를 맨 위에서 조절 |
| `PetReactions.ts` | 쓰다듬는 동안의 반응 연출 (유예·이어하기·출렁 복귀 포함) |
| `team-structure-walk/` | 팀 구조(`features/healing/walk/`)에 맞춘 산책 버전. 이동 계산 + `#character` 를 읽기 전용으로 옮기는 화면 연결 + 테스트 10개 |

`frames-README.md`는 프레임 규격 설명입니다. 서 있는 몸 높이는 약 150px, 발바닥 기준선은 동작마다 통일했고, 배경과 그림자는 제거했습니다(그림자는 렌더러가 직접 그림).

> 눈 뜬 대기 프레임은 팀장님 브랜치에 같은 경로(`idle/idle-frame-NN.png`)의 파일이 있어서, 합칠 때 충돌하지 않도록 **`idle-open`** 이라는 이름으로 지었습니다.

## 산책 숫자 (`WalkController.ts` 맨 위)
`stopDistance`(멈추는 거리), `maxSpeed` / `minSpeed` / `slowdown`(속도). 초당 픽셀 단위라서 화면 크기나 컴퓨터 성능에 상관없이 같은 속도로 움직입니다.

팀 의견을 받으며 속도를 이렇게 조절했습니다. (시간은 가상의 계산으로 잰 값)

| 단계 | maxSpeed | minSpeed | slowdown | 화면 가로지르기 | 계기 |
|---|---|---|---|---|---|
| ① 처음 | 420 | 70 | 3 | 2.8초 | 처음 만든 값 |
| ② 빠르게 | 800 | 140 | 6 | 1.5초 | "더 빠르게" |
| ③ 중간 | 610 | 105 | 4.5 | 1.9초 | 팀: "조금만 줄여 달라" |
| ④ 조금 더 느리게 | 500 | 90 | 4 | 2.3초 | "좀 더 느리게" |
| **⑤ 현재** | **300** | **55** | **2.4** | **3.9초** | 팀: "다리가 짧으니 따라오는 데 시간이 걸리면 더 귀엽다" |

## 배운 것
- **창을 화면 전체로 덮으면 마우스 움직임을 어디서나 받을 수 있습니다.** 클릭은 통과시키면서(`setIgnoreMouseEvents(forward)`) 움직임만 받아서, 산책의 목표 지점으로 씁니다.
- **걷다 멈췄다를 반복하는 떨림은 "시작 거리"와 "멈춤 거리"를 다르게 두면 막을 수 있습니다.** (히스테리시스: 120px 밖이면 걷기 시작, 90px 안이면 멈춤)
- **갈 수 없는 곳(화면 맨 위, 화면 밖)에 커서가 있으면** 목표를 갈 수 있는 범위로 맞춰 줘야 제자리에서 허우적대지 않습니다.
- **GIF/영상에서 투명 PNG 만들기:** 배경색이 "투명"이 아니라 칠해진 색이라서, 가장자리에서 배경을 따라 지우고(flood fill) 그림자를 제거했습니다. 외곽선 바깥의 하얀 점은 가장자리 한 줄을 외곽선 색으로 칠하고 떨어진 점을 지워서 정리했습니다.
- **같은 이름의 폴더·파일이 다른 사람의 것과 겹치지 않는지 합치기 전에 확인합니다.** (`idle` → `idle-open`)

## 알아 둘 점
- 이 폴더만으로는 실행되지 않습니다. 팀 저장소의 앱 뼈대(창, 카메라, 힐링 인식)가 필요합니다.
- 산책은 캐릭터 위치를 직접 움직이기 때문에, 팀 구조(팀장님 렌더러)에 어떻게 넣을지는 팀과 정해야 합니다.
- 캐릭터 이미지 프레임은 저작권이 원작자에게 있어서 이 공개 저장소에는 올리지 않았습니다.
