# 힐링 데모: 새 캐릭터 + 쓰다듬기 + 산책

팀 프로젝트 [ChiiPT](https://github.com/HongJC-PortFolio/ChiiPT)의 힐링 파트를 **팀 코드와 분리해서 테스트**하던 데모(`ChiiPT-demo`)의 기록입니다. 이 폴더에는 **내가 작성한 파일만** 담았고, 다른 팀원의 코드와 캐릭터 이미지는 포함하지 않았습니다.
(AI 코딩 도구 Claude Code와 단계별로 설명을 들으며 함께 작성했습니다.)

## 데모에서 되는 것
| 기능 | 설명 |
|---|---|
| 새 캐릭터 프레임 재생 | 대기 / 눈 감은 대기 / 걷기(좌우) 등을 프레임 PNG로 재생 |
| 쓰다듬기 반응 | 힐링 모드에서 쓰다듬으면 눈 감은 얼굴 + 부비부비 → 웃음 → 총총, 하트 |
| 산책 | 마우스를 따라 화면 어디든(좌우·상하·대각선) 걷기, 끄면 화면 아래 가운데로 복귀 |

우클릭 메뉴의 `힐링 모드`, `산책`을 켜고 끕니다. 쓰다듬기 인식(손 랜드마크 → petting 판정)은 팀원의 코드를 그대로 사용했습니다.

## 파일 (`src/`)
| 파일 | 역할 |
|---|---|
| `motions.ts` | 동작 목록. 프레임 수, 재생 속도(fps), 캔버스 크기, 발바닥 기준선 |
| `CharacterView.ts` | 프레임 재생, 위치(발바닥 중앙 좌표), 클릭 영역(몸 위 타원) |
| `WalkController.ts` | 산책 이동 계산. 커서를 따라가고, 멈추는 거리/속도 등 숫자를 맨 위에서 조절 |
| `PetReactions.ts` | 쓰다듬는 동안의 반응 연출 (유예·이어하기·출렁 복귀 포함) |

`frames-README.md`는 프레임 규격 설명입니다(서 있는 몸 높이 약 150px, 발바닥 기준선 통일, 배경·그림자 제거).

## 산책 숫자 조절 (`WalkController.ts`)
`stopDistance`(멈추는 거리), `maxSpeed` / `minSpeed` / `slowdown`(속도). 초당 픽셀 단위라서 화면 크기나 컴퓨터 성능에 상관없이 같은 속도로 움직입니다.

## 알아 둘 점
- 이 폴더만으로는 실행되지 않습니다. 팀 저장소의 앱 뼈대(창, 카메라, 힐링 인식)가 필요합니다.
- 산책은 캐릭터 위치를 직접 움직이기 때문에, 팀 구조(팀장님 렌더러)에 어떻게 넣을지는 팀과 정해야 합니다.
- 캐릭터 이미지 프레임은 저작권이 원작자에게 있어서 이 공개 저장소에는 올리지 않았습니다.
