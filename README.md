# ChiiPT_by.me 🫳🐾

웹캠으로 내 손을 인식해서, 화면 속 캐릭터를 **쓰다듬으면 반응하는** 데스크톱 펫 연습용 프로젝트입니다.

해커톤 팀 프로젝트 [ChiiPT](https://github.com/HongJC-PortFolio/ChiiPT)에서 제가 맡은 **힐링(쓰다듬기) 기능**을 먼저 혼자 만들어 보며 배운 과정을 기록한 저장소입니다. 최종본은 팀 저장소의 구조(`features/healing/`)에 맞춰 옮길 예정입니다.

> **작업 방식:** Electron·MediaPipe 개발이 처음이라, AI 코딩 도구(Claude Code)와 함께 단계별로 만들었습니다. 코드를 받아 쓰기만 하지 않고, 각 단계마다 "무엇을, 왜 이렇게 짜는지" 설명을 듣고 직접 실행해 확인하며 진행했습니다. 아래 "배운 것"은 그 기록입니다.

## 지금 되는 것

- 투명한 **전체화면 오버레이**에 캐릭터 표시 (다른 프로그램 위에 항상 표시, 빈 곳은 클릭 통과)
- 웹캠으로 **손 위치 인식** (MediaPipe Hand Landmarker) → 🫳 커서가 손바닥을 따라 이동
- 캐릭터 머리 영역에서 **쓱쓱 쓰다듬는 동작 판정**
- 쓰다듬는 동안 캐릭터가 **흔들리고 하트**가 나옴, 3초 넘게 쓰다듬으면 **더 크게 반응**
- 손을 멈추거나 떼면 원래 상태로 복귀

영상은 저장하거나 외부로 보내지 않고, 이 컴퓨터 안에서만 처리합니다.

## 실행 방법

필요한 것: Node.js (개발은 v26에서 진행), 웹캠

```bash
npm install
npm run setup   # 손 인식 모델과 wasm 파일 준비 (최초 1회, 인터넷 필요)
npm run dev
```

- 처음 실행하면 카메라 권한 팝업이 뜹니다. **허용**해 주세요. (macOS)
- 종료: `Cmd + Shift + Q` (Windows는 `Ctrl + Shift + Q`). 창이 클릭을 통과시키고 포커스도 받지 않아서 임시로 넣은 단축키입니다.
- 캐릭터 머리 주변의 분홍 점선 박스가 쓰다듬기 판정 영역입니다. 그 안에서 손을 좌우로 쓱쓱 움직여 보세요.

```

    └── src/

        ├── vision/handTracker.ts          # 웹캠 + MediaPipe (손바닥 중심 좌표)
        ├── interaction/pettingDetector.ts # 쓰다듬기 판정 (순수 계산)
        ├── interaction/character.ts       # 캐릭터 겉모습 (흔들기, 하트)
        └── assets/                        # 캐릭터 이미지

```

## 배운 것

### 1. Electron은 코드가 세 부분으로 나뉜다
- **메인**: OS 기능(창, 카메라 권한, 단축키)을 다룸
- **렌더러**: 웹페이지처럼 화면을 그림
- **프리로드**: 둘 사이에서 허용한 기능만 연결 (보안)

둘은 서로 직접 접근할 수 없어서 IPC(메시지 주고받기)로 통신합니다. 예: 마우스가 캐릭터 위에 올라오면 렌더러가 메인에 "클릭을 받아 줘"라고 알립니다.

### 2. 투명 오버레이 만들기
- `transparent`, `frame: false`, `hasShadow: false`: 배경·테두리·그림자 제거
- `alwaysOnTop` + `'screen-saver'` 레벨: 전체화면 앱 위에도 표시
- `setIgnoreMouseEvents(true, { forward: true })`: 클릭은 통과시키되 마우스 움직임은 계속 받음
- 창을 **화면 전체 크기**로 만든 이유: 손 커서가 화면 어디든 그려져야 하고, 캐릭터 위치를 CSS로 자유롭게 정할 수 있어서

### 3. GIF에는 투명도가 없었다
받은 GIF의 배경이 "투명"이 아니라 **하늘색으로 칠해진 픽셀**이어서 창이 투명해도 보였습니다. 이미지 모서리부터 배경색을 따라가며 지우고(flood fill), 가장자리의 밝은 번짐을 몇 픽셀 깎은 뒤, 반투명을 지원하는 **움직이는 PNG(APNG)** 로 저장했습니다. 원본은 `pet-idle.original.gif`로 보관합니다.

### 4. 손 좌표를 화면 좌표로 바꾸기
- **좌우 반전**: 웹캠은 실제 방향 그대로 찍혀서 `1 - x`로 거울처럼 뒤집어야 손 방향과 커서 방향이 맞음
- **가운데만 사용**: 카메라 화면의 15~85%만 화면 전체에 대응시켜서 팔을 조금만 움직여도 구석까지 닿게 함
- **손바닥 중심을 커서로**: 손목과 손가락 뿌리 5개 점의 평균. 손가락 끝은 많이 흔들려서 부적합
- **떨림 완화**: 지수 이동 평균(새 값을 35%만 반영)

### 5. 쓰다듬기는 "방향이 바뀐 횟수"로 판정한다
단순히 "손이 머리 위에 있다"로는 지나가는 손과 구별이 안 됩니다. 쓰다듬기의 특징은 **왔다 갔다 하는 것**이라서:
- 최근 1.2초의 손 움직임에서 **방향 전환 횟수**를 셈 (25px 이상 움직여야 한 번으로 인정 → 손 떨림 무시)
- 시작은 전환 2번, 유지는 1번으로 기준을 다르게 둠 (끊김 방지, 히스테리시스)
- 머리 영역을 벗어날 때는 30px 여유를 둠 (경계에서 깜빡이는 것 방지)
- 상태: `idle → approach → petting → ending → idle`

판정 로직은 화면과 무관한 순수 계산이라서, 가상의 손 움직임으로 시뮬레이션해 검증했습니다.

| 가상 움직임 | 결과 |
|---|---|
| 쓱쓱 2초 | 쓰다듬기 시작 |
| 쓱쓱 5초 | 쓰다듬기 → 더 기뻐함 |
| 쓰다듬다 멈춤 | 종료 |
| 그냥 지나가기 | 쓰다듬기 아님 |
| 손 떨림(±4px) | 쓰다듬기 아님 |
| 머리 밖에서 쓱쓱 | 반응 없음 |

### 6. 역할 분리
`handTracker`(카메라와 인식) / `pettingDetector`(판정) / `character`(겉모습)로 나눠 두었습니다. 나중에 캐릭터 그림이나 애니메이션 엔진이 바뀌어도 판정 코드는 그대로 쓸 수 있고, 팀의 공용 카메라·캐릭터 컨트롤러와 합칠 때도 이 경계에 맞추면 됩니다.

## 튜닝

`pettingDetector.ts` 맨 위의 숫자로 쓰다듬는 느낌을 조절합니다.

| 값 | 의미 | 반응이 안 올 때 | 너무 예민할 때 |
|---|---|---|---|
| `MIN_AMPLITUDE` | 한 번으로 인정할 최소 움직임(px) | 줄이기 | 늘리기 |
| `START_REVERSALS` | 시작에 필요한 방향 전환 횟수 | 줄이기 | 늘리기 |
| `VERY_HAPPY_AFTER_MS` | "아주 기뻐함"까지의 시간 | - | - |

`main.ts`의 `DEBUG_SHOW_ZONE`을 `false`로 바꾸면 분홍 점선 박스가 사라집니다.
